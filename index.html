Before you join a string

Peers on a string connect to each other directly, browser to browser, so they can see your IP address. Public WebTorrent trackers are used to find each other; they see it too. Connections are encrypted, and a world's game server is never reachable except through them.

Your game files. WoW Electrode does not include World of Warcraft or its game files: the game runs on your own copy of the 1.12.1 game files. By accepting, you confirm that the game files you use are your own copy, one you own or purchased in the past.

Shown once. Joining a string and playing solo wait until you accept.

Add your World of Warcraft 1.12.1 game files

Choose your own 1.12.1 (build 5875) folder, or its Data folder. The 14 archives are read where they are: nothing is copied, nothing is uploaded, and game files are never shared with peers. Chrome and Edge remember the folder and ask once per visit before reading it again; other browsers ask for the folder each visit.
